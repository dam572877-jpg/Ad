# DREAM HOUSE — Classic Executive V22

نسخة Mobile-First احترافية لنظام إدارة العقارات، جاهزة للعمل على GitHub Pages.

## التشغيل على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر الـRepository.
2. تأكد أن `index.html` موجود في أول مستوى.
3. من Settings → Pages اختر Deploy from branch ثم `main` و`/(root)`.
4. افتح رابط الموقع بعد اكتمال النشر.

## ملاحظات
- البيانات محفوظة محليًا في المتصفح.
- يوجد Backup / Restore داخل قسم البيانات وPDF.
- تقارير PDF تستخدم العقارات المحددة فقط وتدعم صفحات متعددة.
